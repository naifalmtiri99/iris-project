\# Iris Dataset Analysis



\## Project Overview

This project analyzes the Iris dataset using Python and Pandas.

The dataset contains 150 rows and 5 columns representing three Iris species.



\## Setup Instructions

1\. Install uv.

2\. Open a terminal in the project folder.

3\. Create the virtual environment using `uv venv`.

4\. Install the project dependencies using `uv sync`.

5\. Start Jupyter Notebook using `uv run jupyter notebook`.

6\. Open `iris\_analysis.ipynb` and run the cells from top to bottom.



\## Analysis Summary

\- Loaded and explored the Iris dataset using Pandas.

\- Examined the dataset shape, columns, and data types.

\- Analyzed the three Iris species.

\- Filtered flowers with sepal length greater than 6.

\- Saved the species summary and filtered data as CSV files.

\- Created a bar chart comparing average petal length.



\## Key Finding

Virginica has the highest average petal length, followed by versicolor and setosa.



\## Project Files

\- `pyproject.toml`: Project configuration and dependencies.

\- `uv.lock`: Locked dependency versions.

\- `iris\_analysis.ipynb`: Analysis and visualization notebook.

\- `data/iris.csv`: Original dataset.

\- `output/species\_summary.csv`: Species summary.

\- `output/filtered\_iris.csv`: Filtered dataset.



The `.venv` folder must not be included in the submission ZIP.
